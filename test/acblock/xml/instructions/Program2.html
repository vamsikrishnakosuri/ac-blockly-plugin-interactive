Scenario E1 — Insert a block from the Toolbox using the keyboard

Goal: Add a Print block inside the Repeat-While block and set its text to Water seed.

  1. Navigate to the target Repeat-While stack and focus the While block.
  2. Press E to enter Edit mode; press F to focus the DO (nested) connection.
  3. Press T to open the Toolbox. Use W/A/S/D to move to the Text category and highlight Print.
  4. Press Enter to insert the Print block at the focused DO connection.
  5. Press D to move into the inserted block, then D again to focus its text field. Type Water seed and confirm (e.g., Enter).
  6. Press E to exit Edit mode.

Completion: A Print “Water seed.” block is placed inside the DO of the Repeat-While block.

Scenario E2 — Detach and attach a block

Goal: Move the Print “Jack plants a magic bean.” and increment count blocks from the Repeat DO into the WHILE DO.

  1. Navigate to Repeat 3 times; press F to select the nested block in the DO.
  2. Press Ctrl+X to cut (detach) the selected block(s).
  3. The cursor switches to workspace mode and a marker is activated. Move the marker with Shift+W/A/S/D; approach the WHILE stack and press F to select the stack.
  4. Press F twice to select the Print statement under the WHILE block, then press E to enter Edit mode. Press S to focus the bottom connection.
  5. Press Ctrl+V to paste (attach) the blocks.
  6. Press E to exit Edit mode.

Completion: The selected blocks are moved from Repeat into the WHILE block’s DO.
