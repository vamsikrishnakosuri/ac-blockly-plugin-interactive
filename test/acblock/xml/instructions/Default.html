Build a program

Goal: To build the above program.

Step 1 — Enable Keyboard Navigation

Goal: Land on the Blockly workspace and activate keyboard navigation.

  1. Press Ctrl+Shift+K to enable Keyboard Navigation.
  2. Focus will land on the workspace with a blinking marker.
keys
Ctrl+Shift+K, W,A,S,D
category
Activation

Step 2 — Navigate to Toolbox

Goal: Open the toolbox and insert the Repeat block.

  1. Press T to open the Toolbox.
  2. Use W/A/S/D to move across categories (e.g., Loops).
  3. Navigate to highlight the Repeat block.
keys
T, W,A,S,D
category
Toolbox Navigation

Step 3 — Insert a Block from Toolbox

Goal: Insert a Repeat block into the empty workspace.

  1. With the Repeat block highlighted in the toolbox, press Enter to insert it into the workspace.
  2. The block appears in the workspace and focus shifts to it.
keys
Enter, D
category
Toolbox & Insertion

Step 3 — Insert a Print Block inside the Repeat block

  1. With the Repeat block highlighted, select nested connection
  2. Press D to select first connection then A to select the nested connection
  3. Now, Press T to go toolbox by pressing S navigate to Text category and press D to enter flyout items
  4. Select print block and press Enter to insert it inside the Repeat block
keys
Enter, D
category
Toolbox & Insertion
