Scenario N1 — Focus a nested variable inside an arithmetic expression

Goal: Within Repeat 3 times, navigate into the nested set count statement and focus the inner variables_get “count” inside the arithmetic count + 1.

  1. Press Ctrl+Shift+K to activate keyboard navigation mode. The whole Stack A is selected.
  2. Press F to focus the top block (set count to 0).
  3. Press S to move to the next block (Repeat 3 times).
  4. Press F to enter the Repeat 3 times block. Focus lands on the first nested block (Print “Jack plants a magic bean.”).
  5. Press S to move to the next nested block (set count to …).
  6. Press F to go inside the set count block and focus the arithmetic count + 1.
  7. Press F again to focus the nested count variable inside the arithmetic expression.

Completion: Focus is on the inner variables_get “count” within count + 1 inside the nested set count block of Repeat 3 times.

Scenario N2 — Use Navigational Assistant & Shortcuts Menu

Goal: Open the Navigational Assistant, review available movement keys, and close it.

  1. Press Alt+H to open the Navigational Assistant.
  2. Use W/S to traverse the list of keys and possible movements.
  3. Press Esc to close the assistant.

Scenario N3 — Focus the number field in a conditional

Goal: Move to Stack B and focus the number field 3 in the conditional count == 3 inside the if-do block.

  1. Press E to exit Edit mode (if active).
  2. Press Alt+Shift+G to open the Search menu.
  3. Select Stack B from the list. Focus jumps to the top block of Stack B ( if-do).
  4. Press D to move inside the if-do block and land on the logic block (count == 3).
  5. Press F to focus the left-hand side of the logic block (the count variable).
  6. Press D to move to the arithmetic operator (==).
  7. Press D again to move to the number field (3).
  8. Press E to enter Edit mode on the number field 3.

Completion: Focus is on the number field 3 in the count == 3 condition within Stack B, with Edit mode active.
